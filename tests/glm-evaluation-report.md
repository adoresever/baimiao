# GLM-5.2 四轮测试报告

## 测试合同

- 模型：`GLM-5.2`
- 测试范围：工作总结、邮件、产品介绍、社交文字、知识解释、人物故事、观点评论、高约束说明
- 每个请求完整加载 `SKILL.md`、`guided-methods.md` 和 `review-rubric.md`
- 请求不设置 `max_tokens`
- HTTP 客户端不设置超时
- 四路并发，8 个案例各自独立请求

## 评审硬门

1. 原意守恒；
2. 零新增事实；
3. 文体守恒；
4. 高约束文字保护。

失败数是针对现有 8 个样本的人工评审结果，不代表整体模型通过率。

## 第四轮摘要

- 工作总结：删除模板连接词，保留三个工作事实及质量判断。
- 邮件：减少过度客套，保留请求、附件、意见和感谢。
- 产品介绍：删除空泛形容词，没有虚构自动分类等具体功能。
- 社交文字：从已有咖啡馆动作开始，没有补写手机或环境细节。
- 知识解释：删除“所谓、顾名思义”等书面脚手架。
- 人物故事：使用原文已有的提前到岗动作，没有补写物件和表情。
- 观点评论：保留“担心”和“可能”，没有把风险写成既成事实。
- 高约束说明：逐字返回。

完整输出见 `glm-results.json`，前三轮分别保存在 `glm-results-v1.json`、`glm-results-v2.json` 和 `glm-results-v3.json`。
